# VeadotubeVnyanProp
Veadotube Vnyan Prop for using a png tuber in vnyan through the spout2 pluggin

Please load the invisible avatar included in the latest version of Vnyan under 2DAvatarFiles called "invistavaar.vsfavatar".
Once the avatar is loaded, add the prop included in this repository called "Spout2VeadoTube.vnprop".
If configured correctly, you should now see your png tuber in vnyan.  Adjust the prop accordingly to desired specifications.
